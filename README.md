# NOCTURNE: The Hollow Throne

**A dark-fantasy dungeon crawler and homestead.**<br>
Rebuild a ruined keep by day. Descend nine dominions of a drowned, burning, bone-white underworld by night.

</div>

---

This page is where the game is downloaded. Open **[Releases](../../releases/latest)** and pick your platform.

## Download

| Platform | File | How to play |
|---|---|---|
| Windows (installer) | `NOCTURNE-The-Hollow-Throne-Setup.exe` | Run it, follow the steps, start the game from the Start menu or desktop shortcut. |
| Windows (zip) | `NOCTURNE-The-Hollow-Throne-windows.zip` | Unzip anywhere, open the folder, run `Game.exe`. |
| Linux (64-bit) | `NOCTURNE-The-Hollow-Throne-linux-x64.tar.gz` | Unpack it, then run `./nocturne.sh` in the folder. |

Nothing to install besides the game itself: it ships with its own runtime. On Linux the usual desktop libraries must be present (GTK 3, NSS, ALSA, X11); on Debian or Ubuntu: `sudo apt install libgtk-3-0 libnss3 libasound2 libxss1 libxtst6`. The Linux build has not been played yet on a real Linux machine, so please report problems. Saves are kept next to the game (zip and Linux) or in its install folder (installer).

## About the game

You come to in the cold hall of Hollowkeep, a Sovereign who has lost their own name. By day you till the soil, fish, cook, brew, forge, hire sellswords and restore the keep. By night you take your lantern down through nine dominions, fight for your party's nerve as well as its health, and judge nine thrones. Dark, quiet and a little wrong.

- Text in English, French, German, Spanish and Serbian (Latin and Cyrillic). The translations are machine-made first passes.
- Keyboard, mouse and gamepad; optional narration through the system voice.

## Status

An early build (version 0.1.0). All of the content is in; it has been tested by automated tests but not yet played through by people. If something goes wrong the game says where its `errors.log` is (Options > About and Problems).

The game is made with RPG Maker MZ and AI-assisted art and music. The source is not published here.
